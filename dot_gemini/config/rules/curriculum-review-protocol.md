# 全域教材與試題生成三階段審查規範 (Curriculum Review Protocol v4.0 逐字逐句深層檢驗版)

> **全域強制約束**：本規範適用於本機所有專案。未來任何專案中，凡涉及生成或修改**教材、考卷、學習單、教學簡報、作業評量或各類教學文件**時，**皆必須嚴格通過三階段審查機制檢驗後始得輸出交付**。

---

## 🛑 階段一：必須符合階段（Must-Have 絕對紅線門檻，未達一票否決打回重置）

1. **逐字逐句真理檢驗（Ground Truth Substring Match）**：
   - 題幹、選項（A/B/C/D、①②③④）、填空括號【】、「」與好詞庫中之實質詞彙，**凡未出現在本機教材/習作真實文本中者，直接一票否決打回重置，禁止交付**。
2. **精準排除三項雜訊干擾**：
   - ① **過濾過去教過**：即使一至三年級學過（如「珍珠、拍手、看見」），只要四上當冊教材未收錄，嚴禁用於核心命題考點或關鍵填空。
   - ② **過濾分析誤判**：排除排版功能詞與試卷說明（如「下列、何者、正確、錯誤、每題分」等功能性系統詞）。
   - ③ **過濾字形或字音幻覺（排除類似音/類似字）**：嚴禁因字形相近（如「己/已/巳」、「拔/撥」、「戊/戌/戍」）或同音近音（如「見狀/現況」、「巡視/尋事」）而產生幻覺誤判，必須以精確 Substring 與真理字串比對為唯一依據。
3. **108 課綱代碼與版本對齊**：
   - 必須明確標註並對齊 108 課綱學習表現代碼與學習內容代碼（如數學 
-Ⅱ-7、國語 6-Ⅱ-1、社會 社2a-Ⅱ-1 等）。
   - 四年級固定鎖定：📘 數學（南一版）、📙 國語（翰林版）、📗 社會（康軒版）。
4. **跨 Agent 教科書版權重要規範**：
   - 嚴禁 commit/push 出版社課本/習作 PDF。若偵測到缺失，主動提示使用者備齊教材。

---

## ⚠️ 階段二：大部分符合階段（Should-Have 教學重點謹慎使用，嚴格標記提醒）

1. **鎖定正式生字表（禁止非生字充當考點）**：
   - 國語科第一大題（寫國字注音）或生字考點，**必須 100% 來自當冊正式「課本生字表（認讀/習寫欄）」**。
   - 若考點雖在課本課文中出現、但非生字表列字（例如課文中出現「美、看、走」等非本冊生字），列為**教學重點違規警告**，必須更換為正式生字。
2. **單元核心概念用詞對齊**：
   - 數學與社會科核心詞彙必須完全對齊單元核心概念（如除法直式術語、家鄉地形專有名詞）。
3. **認知負荷理論 (CLT)**：
   - 核心思考元素控制在 3~4 塊內，版面維持適度留白，避免認知超載。

---

## 🌟 階段三：盡力符合階段（Nice-to-Have 跨題型邏輯性、適配性與防洩題自我碰撞）

1. **零跨大題洩題碰撞（Zero Cross-Leaking Invariant）**：
   - 前面大題所考之生字、注音或改錯字考點（如第一大題考【鷹】、【翔】），**嚴禁在後續大題（選擇題題幹、改錯字題目、閱讀測驗篇章）中出現正字洩漏答案**！
2. **考點不重複與篇章邏輯適配**：
   - 同一份評量中，嚴禁不同大題重複考查同一字詞，情境短文全篇主題必須一氣呵成，動賓搭配自然。
3. **加分亮點達成**：
   - SDGs 永續發展目標融入（SDG 14 海洋生態、SDG 12 責任消費、SDG 7 潔淨能源）。
   - 海線在地生活情境（梧棲、中正國小、高美濕地、九降風、風力發電）。
   - 四年級典型迷思概念誘答設計（如 M4-FRAC-01、C4-TEXT-01、S4-LOCAL-01）。

## 🔄 同型態輸入輸出原則與輸出標準

1. **格式對等交付 (Format Parity)**：輸入 Markdown 輸出優化 Markdown，輸入 HTML 輸出優化 HTML。
2. **集中輸出**：一律輸出至 
eviewed/ 專屬目錄，原檔案保持乾淨。
3. **必備審查報告**：文末或隨附必須包含標準化《AI 自我檢測審查報告 (Self-Review Report v4.0)》，清楚標明階段一、階段二與階段三檢測狀態。
