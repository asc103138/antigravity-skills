# Teacher Slide Image Workshop

用 AI 把教師的教學想法、簡報規格、參考圖片、角色圖或既有 PDF／DOCX，轉成逐頁獨立生成的 16:9 簡報圖片。

這是一個給 Codex 使用的 Skill。GitHub 儲存庫負責保存與分享 Skill；實際的簡報圖片生成會在安裝 Skill 的 Codex 工作階段中執行。

## 這個 Skill 可以做什麼

- 引導教師整理主題、受眾、頁數與教學目標。
- 閱讀完整的 PDF、PPTX、DOCX、文字大綱與設計說明。
- 分辨風格／排版參考圖、角色身份參考圖與內容參考資料。
- 維持固定主角的髮型、臉型、服裝與視覺風格。
- 使用 AI 生圖功能，一張投影片獨立生成一張圖片。
- 輸出編號 PNG、README.txt 與完整簡報資料夾。
- 生成前後檢查頁數、編號、尺寸、16:9 比例與圖片可讀取性。

## 在 Codex 中使用

安裝或匯入這個 Skill 後，在對話中輸入：

```text
$teacher-slide-image-workshop
```

接著直接描述教學想法，並依照引導上傳資料。例如：

```text
$teacher-slide-image-workshop

請幫我製作一套給國中資源班教師使用的簡報，主題是「AI 融入特殊教育」。
請先閱讀我上傳的簡報規格與設計說明，再參考角色圖片中的老師作為每一頁的主角。
最後請逐頁獨立生成 16:9 簡報圖片，輸出成編號完整簡報資料夾。
```

## 建議準備的資料

1. 內容來源：PDF、PPTX、DOCX、文字大綱或教學想法。
2. 風格／排版參考圖：用來控制配色、版面、卡片與視覺氣氛。
3. 角色身份參考圖：固定教師、學生或其他主角的外觀；請明確說明「這是角色參考圖」。
4. 設計說明：包含頁數、畫面文字、色彩、字體、版型或品牌規範。

如果沒有指定頁數，Skill 會依內容規模提出建議。若來源頁數與指定頁數不同，會先指出差異，不會自行刪頁、合併或增加頁面。

## 生成流程

1. 讀取並整理所有來源資料。
2. 建立逐頁內容清單與視覺契約。
3. 為每一頁建立獨立的 AI 生圖任務。
4. 固定角色身份與整套投影片的版型、色彩及構圖語言。
5. 逐頁生成圖片，檔名使用 `01.png`、`02.png` 等零填充編號。
6. 檢查圖片數量、尺寸、比例、編號與中文文字可讀性。
7. 輸出完整簡報資料夾。

## 輸出內容

最終資料夾通常包含：

```text
完整簡報資料夾/
├── 01.png
├── 02.png
├── ...
├── 最後一張.png
└── README.txt
```

每張投影片都是獨立的 16:9 PNG，不使用程式碼繪圖、HTML、SVG、Canvas 或圖片合成來取代 AI 生圖。

## 注意事項

- 若希望每一頁都出現同一位老師，請提供清楚的角色身份參考圖。
- 參考圖只會用來控制風格、排版或角色身份，不會直接複製其中的文字內容。
- 若需要畫面上有精確繁體中文，請在需求中提供逐字文字，並在生成後檢查可讀性。
- 請避免上傳學生姓名、病歷、聯絡方式或其他不必要的個人資料；真實案例請先匿名化。
- AI 生圖不可用時，Skill 會清楚說明原因，不會改用程式化繪圖冒充完成。
