# 國小四年級教材與試題三階漏斗審查規範 (G4 Curriculum Review)

本機制為臺中市梧棲區中正國民小學四年級專屬教材、試題與學習單生成之三階漏斗自我檢測審查協議。

---

## 📘 核心教科書版本鎖定

所有生成內容必須嚴格對齊以下教科書版本，禁止跨版本混用：
- 📘 **數學科**：南一版
- 📙 **國語科**：翰林版
- 📗 **社會科**：康軒版

---

## 🔍 三階漏斗審查機制 (Three-Tier Funnel Review)

所有四年級生成的教材、試題或學習單，在交付前皆須通過或標註此三階檢測：

### 🛑 第一階：最低門檻（Must-Have，紅線標準）
- **規範**：
  1. 嚴格符合四年級學生先備經驗（不得出現高年級或未學過之進階算則/生字/概念）。
  2. 108 課綱學習表現代碼與學習內容代碼對照（如數學 `n-Ⅱ-7`、國語 `6-Ⅱ-1` 等）。
  3. 精確對齊指定教科書版本之單元主題與專屬用詞（南一數、翰林國、康軒社）。
  4. **跨 Agent 教科書版權重要提醒**：因版權限制，專案 Git 儲存庫嚴禁 commit 出版社教科書/習作檔案（已於 `.gitignore` 隔離）。**其他 Agent 接手或執行審查前，必須先檢查本機是否已有下載對應課習教材（如 `115四上數課習/`、`115四上國課習/`、`115社會課習/`）。若本機缺少，Agent 必須主動提醒使用者先自行由校內合法教學資源庫下載所需版本的教科書/習作 PDF 放置於專案目錄後再行精確比對。**
- **處置**：**未達標者直接打回重置，不可交付。**

### ⚠️ 第二階：中階目標（Should-Have，盡力達到）
- **規範**：
  1. **認知負荷理論 (CLT)**：四年級題目題幹字數宜精簡，工作記憶元素控制在 3~4 塊內，版面留白適當。
  2. **SDGs 永續發展目標**：生活化融入（如 SDG 14 海洋生態、SDG 12 責任消費）。
  3. **STEAM 跨域思維**：結合科學探究、工程設計或數學生活應用。
- **處置**：未達標或有落差時，啟動 `rdq` 需求探索（以象限Ⅳ一鍵選擇菜單形式）與教師確認後修正。

### 🌟 第三階：高階目標（Nice-to-Have，加分亮點）
- **規範**：
  1. **迷思概念診斷與誘答設計**：選擇題選項需針對四年級典型迷思（例如分數加減連分母也相加、乘除位值混淆）設計誘答與診斷標籤。
  2. **海線在地情境融入**：臺中港區、梧棲漁港、高美濕地、九降風與風力發電等真實鄉土生活情境。
  3. **18項議題與媒體素養**：融入海洋教育、環境教育、品德教育或資訊媒體識讀。
- **處置**：**不勉強**，若達成則在審查報告中列為加分亮點。

---

## 📋 輸出格式要求：AI 自我檢測審查報告

每當生成試題或教材時，文末須附帶標準化自我檢測報告：

```markdown
### 📋 AI 自我檢測審查報告 (Self-Review Report)
- **第一階（最低門檻）**：
  - 先備經驗：[合規說明]
  - 108 課綱代碼：[學習表現 / 學習內容]
  - 教科書版本：[科目與單元]
- **第二階（中階目標）**：
  - 認知負荷 (CLT)：[字數/元素分析]
  - SDGs 融入：[目標編號與情境]
  - STEAM 跨域：[跨學科點]
- **第三階（高階加分）**：
  - 迷思診斷：[誘答設計說明]
  - 在地生活情境：[地名/在地主題]
  - 議題素養：[議題項目]
```
