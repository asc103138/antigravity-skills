# 範例使用

使用者：

> 我要做三年級班親會，大概 30 分鐘。這班比較活潑，我很重視閱讀、生活習慣和孩子自己負責。我希望家長知道，我不是只看成績，也希望家長不要一直代替孩子整理書包。想做溫暖一點、有手繪感。

Skill 應先整理方向，例如：

> 我會把主軸抓成三件事：孩子逐漸學會為自己負責、閱讀是每天累積、成績只是學習證據的一部分。整套約 14 頁，以孩子的一天作為故事主線；前半段建立家長對班級的理解，後半段再談作業、評量與親師合作。視覺採溫暖手繪教室感，文字少、情境圖多。若這個方向可以，我就直接完成整套簡報與網站。

使用者只要回覆「可以」，即進入 Production Mode，之後不得逐頁詢問。
