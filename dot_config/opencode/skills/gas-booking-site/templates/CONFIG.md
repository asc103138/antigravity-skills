# GAS 預約網站模板設定表

使用模板前，先把新需求整理成下列設定。沒有提供的項目沿用模板預設值，不能自行改動資料結構。

## 基本資料

```text
網站標題：
工作表分頁：預約
班級清單：
用途提示：例如：數學 Kahoot 或社會 Padlet
主題：
輸出資料夾：
```

## 週次資料

```text
第一週開始日：2026-08-30
週數：21
每週起始日：星期日
```

週次必須能明確換算成「第 N 週」與日期範圍。若使用學期週次，不要直接套用 ISO 週次。

## 課表資料

```text
星期：星期一、星期二、星期三、星期四、星期五
節次與時間：
第1節 8:40~9:20
第2節 9:30~10:10
第3節 10:30~11:10
第4節 11:20~12:00
第5節 13:30~14:10
第6節 14:20~15:00
第7節 15:20~16:00
```

## 限制與功能開關

```text
禁止預約格：星期一第5～7節、星期三第5～7節
同一次可選多節：是
多節是否限同一天：是
過去週次禁止預約：是
用途必填：是
允許取消：否
允許修改：只修改用途
```

## 模板索引

- `Code.gs`：GAS 後端模板。
- `index.html`：正式網頁前端模板。

修改模板時，優先改常數、文字與 CSS；不要任意更改試算表欄位順序或前後端函式參數。
