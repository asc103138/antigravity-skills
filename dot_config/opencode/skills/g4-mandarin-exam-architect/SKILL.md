# 國小四年級國語定期評量命題與排版全流程技能 (G4 Mandarin Exam Architect)

本技能為 **OpenCode** 與 **Antigravity** 跨 Agent 協同作戰之標準技能規範，專門用於國小四年級國語科（鎖定翰林版）定期評量之題綱規劃、批次命題、三階漏斗審查、JIS B4 橫向直書排版、Word 原生可編輯方格生成、官方雙向細目表與參考答案卷一站式交付。

## 🎯 核心規格與限制

1. **教科書版本鎖定**：
   - 嚴格鎖定**翰林版國語四上**（第 1 課至第 6 課、統整活動一至二），禁止跨版本混雜南一或康軒。
2. **三階漏斗審查強制門檻 (G4-Review v4.0)**：
   - **第一階（最低標準 紅線，未達標直接打回）**：
     - **生字白名單（88 字視覺驗證）與四字成語考點鎖定**：
       - 國語科第一大題（寫出國字和注音）與第二大題（改錯字）之單字考點，必須 **100% 來自經視覺核對之《我會寫字》88 個正式生字白名單 (`chinese_all_official_characters`)**。
       - **嚴禁信賴出版社 PDF 文字層 (`page.get_text()`) 提取生字**：翰林課本/習作 PDF 內之獨立注音與標題注音使用同音漢字編碼字型（如 `ㄒㄩㄣˊ` 編碼為 `巡`、`ㄋㄧㄥˊ` 為 `寧`、`ㄌㄨㄣˊ` 為 `倫`、`ㄖㄨㄥˊ` 為 `榮`、`ㄔㄨㄥ` 為 `衝`、`ㄐㄧㄥˋ` 為 `竟`），且《我會寫字》右下角附有「字詞猜猜看」舊字部件（如 `守生、怖龍、記影、光魂、車流、衝見`）。嚴禁將此類同音字碼、字詞猜猜看提示字或課文內文舊字（如 `造、耀`）列為生字考點！
       - **出題與交付前強制執行 `check_curriculum.py` v4.0**：必須對 `.docx`、`.md`、`.html` 執行 `python C:\Users\ccps\.gemini\config\skills\g4-curriculum-review\scripts\check_curriculum.py <檔案路徑>`，確保 `<w:txbxContent>` 可編輯方格與單字括號 `【X】` 100% 通過 88 生字白名單檢核。
       - 全卷（含選擇題題幹、選項、成語大題）出現之四字詞語/成語必須 **100% 出自課本或習作**。
     - **短文篇章連貫性與詞語搭配自然度（Passage Coherence & Collocation）**：
       - 第一大題（寫出國字和注音）與第二大題（改錯字）之情境短文，**全篇所有段落必須圍繞單一完整故事主軸一氣呵成**（例如：校慶接力賽失誤 → 同學安慰 → 放學留校練習 → 討論接棒技巧為班級爭取光榮 → 研究方法創造佳績）。
       - **嚴禁為了湊齊不同課次生字而在後段硬湊與前文無關的突兀段落**（如前段寫運動會，後段突然跳去寫海灣旅遊或萊特兄弟發明飛機；若需嵌入「灣、島、翔、蔬、耕」等字，必須透過合理譬喻如「像海洋守衛美麗海灣與寶島般團結」、「如鳥兒在天空飛翔」、「像農夫細心培育蔬菜、努力耕耘」自然融入同一故事主線）。
       - **詞語搭配必須自然合乎語感**：替換生字或潤飾句子時，嚴禁出現生硬造詞或動賓搭配不當（例如禁止寫出「改造動作」，應改為「研究方法、創造佳績」），並避免同一句內重複累贅用詞（如重複兩次「努力」）。
     - **專名號全面標註**：全卷所有人名、地名、國名等專有名詞（如「小明」、「萊特」、「臺灣」等）必須全面標註專名號（Word 直書中設定 `underline=True`，呈現於字左側底線）。
     - **零跨大題洩題與自我碰撞**：前面大題所考之生字/注音，嚴禁在後方大題（改錯字、選擇題、閱讀理解）題幹或選項中出現正字洩題；全卷嚴禁重複考查相同字詞。
     - **選項完整與教育部標準字體**：選項不得缺字、漏字；字體必須符應教育部《國字標準字體》（如「汙染」）。
     - **版面規格與頁數硬約束**：JIS B4 橫向直書精確 4 頁（單面 22 欄上限），題目文字微調時嚴格控制字數與折行，嚴禁溢出破版（每次微調後必須以 Word COM 轉出 PDF 並驗證頁數 `== 4`）。
     - **全套交付與分類資料夾連動閉環**：試卷、參考答案卷、教師版、雙向細目表、官方報部表格，以及各分類資料夾（如 `03_學校公版表格/`、`05_期中評量交付成品/`）必須 100% 同步更正。
     - **課綱與超綱紅線**：108 課綱代碼對齊；零超綱（嚴禁自然段/意義段/修辭術語名稱直接入題）。
   - **第二階（中階目標 專業）**：控制認知負荷（題幹簡短明瞭）、生活情境與 SDGs/STEAM 融入。
   - **第三階（高階目標 加分）**：迷思診斷誘答設計（形近字、音近字、句型功能比較）、台中海線（梧棲、高美濕地等）在地情境。

## 🛠️ Word JIS B4 直書排版與「原生可編輯生字方格」規範

1. **嚴禁使用 `w:lineRule="exact"` 於主段落**：
   - 在 Word 直書（`tbRl`）環境中，主段落使用 `exact` 會截斷字符筆畫與方框。主段落一律使用 `w:lineRule="atLeast"` 搭配 `<w:snapToGrid w:val="0"/>`。
2. **紙張標準**：
   - JIS B4 橫向直書（364 mm × 257 mm），標準四面折合版面（單面極限 22 欄）。
3. **生字注音方格強制採用「Word 原生可編輯文字方塊群組 (`wpg:wgp`)」**：
   - **嚴禁使用靜態 `.png` 圖片檔作為生字注音方格**（圖片檔無法在 Word 內直接點選修改生字或注音，且印刷解析度不如向量字型）。
   - **可編輯方格底層架構**（詳見 `scripts/editable_box_builder.py`）：
     - 外層為行內繪圖 `<w:drawing><wp:inline>`，總尺寸鎖定 `cx="584200" cy="406400"`（`46 pt × 32 pt`），確保在直書段落中行高與欄寬零位移。
     - 內層為 `<wpg:wgp>`（WordprocessingGroup），包含左右兩個緊密相連之 `<wps:wsp>` 文字方塊（`txBox="1"`，邊框 `12700 EMUs = 1 pt` 黑框、白底、`lIns=tIns=rIns=bIns="0"`、`anchor="ctr"`）：
       1. **左格（國字格）**：`x="0", y="0", cx="406400" (32 pt), cy="406400" (32 pt)`。內嵌標楷體 `23 pt` (`w:sz="46"`) 置中段落。即使學生版留空，`<w:pPr>` 與 `<w:rPr>` 亦須預先綁定標楷體 `23 pt` 屬性，讓教師在 Word 點擊空白格輸入任何生字時直接套用正確字型大小與置中。
       2. **右格（注音格）**：`x="406400", y="0", cx="177800" (14 pt), cy="406400" (32 pt)`。聲母、介音、韻母分行排列（2 行時 `w:sz="20" (10 pt), line="210"`；3 行時 `w:sz="17" (8.5 pt), line="160"`）。**關鍵防斷行設定**：韻母加聲調（如 `ㄤˇ`、`ㄥˋ`）同行時，段落必須設定 `<w:ind w:left="18" w:right="-150"/>` 與 `<w:spacing w:val="-85"/>`（緊縮字距與負右縮排），使聲調符號緊貼韻母右側而不會被擠到下一行。
       3. **參考答案卷模式**：同一套可編輯方格同時顯示國字與注音，並將考查項目（國字或注音）自動設為紅色（`FF0000`），題目提示維持黑色（`000000`）。

## 👥 雙 Agent 協同分工模式

### 🟢 1. OpenCode 執行指引（批次生成與骨架）
- **觸發情境**：專案啟動時，負責命題初步規劃。
- **執行任務**：
  1. 梳理課次題綱與語料範圍（L01~L06 課文核心、生字表、課習四字成語庫）。
  2. 撰寫第一、二大題 SEL 短文時，確保**全篇各段情節連貫、首尾呼應、動賓詞語搭配自然**。
  3. 依配分比例批次生成題型草案與初版生字成語清冊。
  4. 提交至 Git 倉庫並標註接棒點至 `handoff.md`。

### 🔵 2. Antigravity 執行指引（審查檢核與可編輯排版重構）
- **觸發情境**：接棒 OpenCode 之初版成果或執行教師修題指令。
- **執行任務**：
  1. 執行 G4 三階漏斗比對本機實體課習 PDF 語料，修正非課本生字、非課習成語、不連貫段落與不自然詞語搭配。
  2. 若修改既存 `.docx` 試卷，優先以 **in-place 就地編輯段落 Runs** 方式保留教師先前在 Word 手動調整之細節，並透過 `win32com.client.GetObject(path).Close(False)` 解除資源管理器預覽窗格鎖定。
  3. 使用 `scripts/editable_box_builder.py` 將第一大題 28 個方格建構為 Word 原生可編輯 `wpg:wgp` 雙格文字方塊，產出標準四面 B4 學生版試卷與紅色參考答案卷，並以 Word COM 轉出 PDF 驗證頁數精確為 4 頁。
  4. 同步更新《雙向細目表》（含公版附件三）、《自我檢測審查報告.md》、《期中評量教師版.md》與 `handoff.md`，並鏡像至 Google Drive 所有分類資料夾。
